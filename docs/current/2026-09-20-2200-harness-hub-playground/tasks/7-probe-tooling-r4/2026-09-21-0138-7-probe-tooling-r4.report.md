## Decisions / deviations

1. **Deviation (one-line data addition in `detect.ts`):** brief-verbatim test 3 (`runs the headless agent form for cursor with --workspace`) stubs only the runner and calls the **real** `resolveBinary('cursor')`. On this machine the genuine standalone Cursor agent CLI is installed at `~/.local/bin/agent` (symlink → `~/.local/share/cursor-agent/versions/2026.04.17-*/cursor-agent`), but `~/.local/bin` is not on non-interactive PATH and `~/.cursor/bin/agent` (detect's only non-PATH candidate) does not exist — so the test failed environmentally. The test file is brief-verbatim and untouchable, so the minimal fix was adding `join(homedir(), '.local', 'bin', 'agent')` to `BINARY_CANDIDATES.cursor`. Side benefit: `probe cursor` and detect's roster now find the actually-installed CLI here. Cost if wrong: negligible — one extra `which`/`existsSync` candidate. Full suite + build verified green after the change.
2. No other deviations. `resolveBinary` was already exported by Task 6 (ledger ruling), imported as-is. No new dependencies.
